# My0511 帖子存档 · 纯插件版 4.4.6（Claude 维护）

只有一个 Chrome 插件，不需要本地服务（Agent）、Node、Kimi 或 Telegram。

- **存档**：采集梦溪论坛帖子存成 Markdown。选了存档文件夹后，按帖子编号（tid）合并写入：同一个帖子只有一个 `日期 t帖子号 标题.md` 文件；楼层只增不减；编辑历史全保留；被合并掉的文件移到 `_重复备份/`，不删除。
- **定时发帖**：与 3.9 相同（人工验证码、需核实发帖的保护都保留）。
- **提醒**（4.1）：有人回复你、关注的帖子或 ID 改楼删楼、关键词出现时弹通知，工作台里有记录。
- **取证指纹**（4.1）：每层楼记正文的 SHA-256 和首次采集时间，工作台可核对存档是否被改过。
- **图片存档**（4.1，默认关）：按帖子或按 ID 开启，存到存档文件夹 `_图片/`。
- **工作台**：运行控制、人工验证、提醒、提醒与存图设置、存档全文搜索、按 ID 补采、存档体检、核对取证指纹、需要核实的发帖、最近事件、备份浏览器数据。

## 分工与接口
- 本项目是插件核心的**上游**，由 Claude 维护，按 git 标签发布（`v4.0.0` 起）。
- 本地服务（Agent）、扩展模块和最终产品的合并封装由 ChatGPT 负责（Documents/My0511）。
- 对接方式：[接口说明](docs/接口说明.md)（后台接口 `My0511API`、扩展模块接入点）和 [存档格式规范](docs/存档格式规范.md)（文件接口）。

## 安装
Chrome → `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选 `extension/`。图标为红色「梦」，名称「My0511 帖子存档 · 纯插件版」。
在「设置」里把存档位置选成存档文件夹（例如「下载 / My0511存档」）。不选文件夹时只能整份写到「下载」，不做合并。
