# 验收矩阵与复现方式

当前已做的验证见 static-checks.json 和 probe-results.json。baseline-probes.cjs 验证的是原版本的行为（包括缺陷），并非宣称修复通过。后续修复时应把对应探针改成“正确行为”的回归断言，不能把确认缺陷仍存在当成发布通过。

## 已完成的离线基线

以 Node.js 执行 audit/baseline-probes.cjs；脚本按自身路径定位同级 v3.7.0 原源码，无外网、无 Chrome、无密钥。模拟 Chrome storage/tabs/alarms，内存暴露 poster 私有函数并替换 doPost。9 个观测都已得到：

| 项目 | v3.7.0 观测 |
|---|---|
| 同一项并发 postOne | doPost 进入 2 次 |
| CAPTCHA 分支 | postCfg.paused 已设，挑战标签仍被关闭 |
| doPost 普通异常 | 条目变 retry，即便异常模拟发生在提交后 |
| 当日额度已用完、缓存计划到期 | reschedule 仍选择该条 |
| worker 重启时 posting | 变 failed，提示人工核实 |
| 成功词+验证词 | classify 返回成功 |
| 短正常帖子提到验证 | isChallengePage 返回 true |
| HTTP 403 验证响应 | 未读取正文，仅 status 错误 |
| 同日同标题、不同 tid | Markdown 文件名相同 |

12 个 JavaScript 文件均通过 node --check；10 个 HTML 脚本引用均存在。未安装项目依赖，原项目没有依赖清单。
