## 使用

本机服务采用 agent/runtime/node (24.18.0)。运行 agent/启动本地服务.command。已运行时不要启动第二份。
分享包不含 runtime、密钥、配对码、机器人绑定、数据库和浏览器数据，也不含项目专用 Node 二进制。接收者需本机 Node.js 24+；无第三方 npm 依赖。
解压后启动 Agent，在 Chrome 加载 extension，使用本机生成的 agent/runtime/pairing-code 配对，然后在「工作台 → 连接设置」填写自己的凭据并按绑定命令完成 Telegram 绑定。
