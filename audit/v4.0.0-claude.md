# My0511 4.0.0 纯插件版（Claude 维护）— 存档合并写入 + 移除 Agent

基线：ChatGPT 3.9.0-dev.8 工作区快照（本仓库提交 b52b5fd，原样复制，未改）。
分工：插件存档侧由 Claude 负责；agent/（Kimi、Telegram、审批）一行未改，归 ChatGPT。

## 要解决的问题
1. 两个插件往同一个文件夹写：3.7 用 `日期 标题.md`，3.9 用 `日期 tNNN 标题.md`，互不相认，产生约 435 份重复。
2. 3.9 每次按浏览器里的数据整份重写文件，会冲掉磁盘上别处采到的楼层和编辑历史（换电脑后浏览器数据为空，问题更明显）。
3. 3.9 选了存档文件夹时，后台不自动写文件（`autoExport` 直接 return），只能在面板里手动导出。

## 设计
- 同一个帖子只认 tid。写入前在文件夹里找这个 tid 的所有文件（t 格式按文件名；旧格式读文件头的 `tid:`），与这次内容合并后写回一个 t 格式文件。
- 合并规则：楼层取并集；同一楼内容不同（忽略空白、引用符号、「本帖最后由…编辑」）时最新版作正文，旧版进 `<details>`；已有历史原样保留、去重；重算 已存楼数 / 改过的楼层 / 首帖 / 最后一楼 / 参与者表。
- 安全：写入前复查修改时间，被改过就重新合并（最多 3 次）；`createWritable` 关闭时整体替换；自检楼层数、历史条数不少于任何输入，否则放弃写入；被合并掉的文件移到 `_重复备份/`（优先 `move()`，否则先复制并核对大小再移除原文件）。
- 后台自动写入走 offscreen 页面（页面环境才能用文件夹句柄）。文件夹授权失效时**不退回「下载」**（下载只能整份覆盖），记为待写，图标显示「授」；在面板点「存档位置」重新授权后自动补写。
- 整帖从第 1 页重采完成后，没再出现的楼层打 `hiddenAt`，文件里标注「已不可见」，原文保留；再次出现时取消。
- `采集时间` 改为北京时间，和编辑历史一致。
- 索引扫描整个文件夹的 t 格式文件重建（导出后 30 秒合并成一次）。
- 没选存档文件夹（「下载」模式）时插件读不到已有文件，行为与 3.9 相同，不合并。**要用合并功能，必须在设置里把存档文件夹选成 Downloads/My0511存档。**
