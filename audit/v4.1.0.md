# 4.1.0（纯插件版，Claude）

## 新功能
1. **提醒**（`alerts.js`）：有人引用或 @ 你（需在工作台填「我的论坛 ID」，没填时用定时发帖设置里的 ID）；关注的帖子或「关注的 ID」改楼、楼不可见；关键词出现在新帖标题（巡查时）或新楼正文。只针对最近 3 天内发的楼；每次最多 12 条，系统通知最多弹 5 条；记录最多 300 条。点通知打开原帖所在页。
2. **取证指纹**：每层楼在采集时计算正文规范文本的 SHA-256（`fp`），改过的楼旧版本保留原指纹；文件里写成 `<!-- 指纹 sha256:… · 首次采集 … -->`。工作台「核对取证指纹」按帖子重新计算核对。4.1 之前采的楼没有指纹，重新采集时补上（补上的指纹对应当时的正文）。
3. **图片存档**（默认关）：面板「保存这个帖子的图片」或工作台「保存图片的 ID」；采完后下载论坛服务器上的图到 `_图片/<tid>/`，楼层里记相对路径。新增权限 `https://*.my0511.com/*`（图片可能在子域名上）。
4. **按 ID 补采**：工作台填 ID（从已存楼层找论坛编号）或编号，打开 Discuz 发帖搜索页 `search.php?srchuid=…`，再用面板的列表批量采集。**该搜索地址尚未在真实论坛验证**；打不开时改用资料页 `viewpro.php?uid=…`。
5. **关键词订阅**：见第 1 条。
6. **存档全文搜索**：工作台按作者、关键词、日期范围搜存档文件夹，显示片段与原帖链接（最多 300 条）。
7. **存档体检**：重复文件（一键合并）、无法解析的文件、中间缺楼或比论坛楼数少的帖子（一键加入队列整帖重采）。
8. 接口 v1.1：`alerts()`、`markAlertsRead()`、`settings()`、事件 `alert`。

## 格式变化（已写入 docs/存档格式规范.md）
- 新增指纹行、图片存档行；合并比较时两者都不算正文，只多了这两行不算修改。

## 验证
- 新增 `test/v41.test.mjs`（5 项）、`test/archive.test.mjs` 新增 1 项；全部 27 项通过。
- 覆盖：指纹从浏览器记录算与从存档文件算一致（引用、# 开头、编辑标记、空正文、未署名引用、不可见、图片行）；旧文件补指纹不算修改；回复提醒只报最近 3 天；关注 ID 改楼提醒带原文；关键词标题只提醒一次；删楼提醒；图片只存开启的帖子/ID、只存论坛服务器上的图、只写进 `_图片/`。
- 未在真实 Chrome 与论坛上端到端验收：通知、图片下载（论坛图片地址与防盗链）、搜索页地址都需要实测。
