# v4.2.3 · 2026-10-10 · 导出/导入队列和设置；补「出错时」测试

## 导出 / 导入（设置页「备份与恢复」）
- `BACKUP_EXPORT`：导出待采队列（未完成的当前帖子放最前，从当时的页接着采）、定时发帖队列（不含已发）、巡查/提醒等设置、`postCfg`、自动跟进名单、跳过记录。不含帖子正文（正文在存档 Markdown 里）。格式 `{format:'my0511-backup', version:1, ...}`。
- `BACKUP_IMPORT`：队列合并去重；设置覆盖；跟进/跳过只补标记，不动已有正文；定时发帖一律以 `held`（暂缓）导入、`plannedAt` 清空，不会导入即发；导入后采集暂停。兼容工作台「备份浏览器数据」的整份导出。帖子编号做格式校验。

## 读帖策略补充
- 断网、超时、论坛 5xx/429 视为临时故障（`isTransientError`），只重试，不计入「连续 3 次失败就跳过」，避免断网时把好帖子全跳过。
- `enqueueThreads` 去重改用 Set（长队列下 O(n)）。
