# v4.2.4 · 2026-10-23 · 修复：论坛验证后点「恢复采集」恢复不了

## 现象
用户在 Edge 装了 NordVPN 浏览器插件后采集停止；删掉 NordVPN 后仍无法恢复采集。

## 原因
VPN 出口 IP 触发论坛验证，插件按设计记下 `humanChallenge` 并暂停。解除它只能在工作台里「打开验证页 → 确认」，而且要求是插件自己打开的那个标签页。面板上的「▶ 恢复采集」遇到 `humanChallenge` 只报「请先完成人工验证」，面板上也不显示原因，用户在论坛里做完算术题也恢复不了。

## 修复
- `RESUME_COLLECT` / `RESUME_ALL`：有待处理验证时，先试读一页版块列表（`clearChallengeIfForumOk`）。论坛正常就解除验证并恢复；仍是验证页、要登录、连不上或页面异常，就保持暂停并说明原因。
- `STATUS` 返回 `challenge`；面板顶部写明「论坛弹出了验证 / 要求登录」以及怎么处理。
- 新增 `test/v424.test.mjs`（3 项）。`node --test test/*.mjs`：48 项全部通过。
