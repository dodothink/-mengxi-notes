# v4.3.0 · 2026-10-26 · 机读存档（存档数据协议 v1）

## 范围
用户确认的缩小范围需求：只改进通用的采集与存档能力，独立于 AI、Telegram 和回复系统。不包含按用户名触发、回复跟踪、跨扩展命令通道或任何发帖相关接口。

## 实现
- 新文件 `extension/archive-data.js`：在存档文件夹维护 `_data/`（`source.json`、`manifest.json`、`threads/<tid>.json`、`journal/*.jsonl`）。
- `ArchiveFolder.writeMerged` 写好 Markdown 后调用 `ArchiveData.publish`：逐帖 JSON → 日志 → 清单（清单最后写＝就绪）。面板手动导出、工作台、后台自动写入都走这一条路。
- 后台：采集完成时附带采集情况（完整/增量、读了哪些页）；采集失败或跳过时记入清单 `lastFailure`；按来源标识记已发布最大序号，识别旧备份覆盖（换代，序号不倒退）。
- 设置页「机读存档」：状态、从现有存档分批重建（每批 150 个文件）。
- 并发：Web Locks（`my0511-archive-data`）串行化面板、工作台、offscreen 的写入。
