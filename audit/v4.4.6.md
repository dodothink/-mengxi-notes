# v4.4.6 · 2026-11-22 · 清单与逐帖 JSON 不一致时自动修复

## 问题
下游 2026-11-15 问题单：4 个帖子（8448119、8558037、8726590、9103825）的 `threads/<tid>.json` 实际校验值和清单 `jsonSha256` 不一致。

## 原因
发布顺序是 Markdown → JSON → 日志 → 清单。JSON 写完、清单写入失败或被打断时，清单停在旧值。4.4.5 新增的“正文没变就跳过”只比较正文校验值，于是这类帖子以后每次都被跳过，不一致一直保留；重建也只比较正文，同样跳过。

## 修复
- `archive-data.js` 新增 `jsonOk()`：读实际 JSON 算校验值。
- `publish()`：正文没变时，只有 JSON 也对得上才跳过；否则重新发布，`revision` 不变。
- `rebuildBatch()`：同样核对 JSON，对不上就重写。
- 代价：正文没变的补写，每帖多读一个小 JSON 文件。
