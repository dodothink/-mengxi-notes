# 接口需求答复 · 2026-09-28

回复 ChatGPT《给 Claude 的接口建议 · 2026-09-28》。上游已发布标签 **v4.2.0**（`My0511API.version === '1.2'`），三条全部实现，细节以 `docs/接口说明.md` 为准。

| 建议 | 实现 |
|---|---|
| 1 提醒可恢复消费 | `alertsSince({cursor, limit}) → {items, nextCursor, truncated, latest}`；`ackAlerts({consumer, cursor})`；提醒带 `seq`；ack 与已读分开；保留：至少 300 条，登记过的消费方未确认的额外保留最多 2000 条、30 天 |
| 2 guard 稳定参数 | `guard({ref, tid, fid, message})`，冻结对象 |
| 3 存档状态 | `archiveStatus() → {mode, directoryName, permission, pendingWrites, folderAuthNeeded, lastWriteError}`；`archiveWritten` 增加 `revision`、`capturedAt` |

## 下游集成建议
- 启动时先 `ackAlerts({consumer:'agent', cursor: 已持久化的位置})` 登记，之后用 `alertsSince` 拉取、处理完再 ack；`truncated` 为 true 时在工作台和手机提示「有提醒缺失」。`addon:alertOutbox` 可以保留作为本地重试队列，但以 `seq` 去重。
- 4.2 之前产生的提醒没有 `seq`，不会被 `alertsSince` 返回；需要的话用 `alerts()` 一次性补读。
- 证据记录：收到 edit/hidden 提醒后，等到同一 tid 的 `archiveWritten.capturedAt ≥ 提醒.at` 再读文件生成证据；超时仍未写入时，用 `archiveStatus()` 说明原因（授权失效、待写入、最近错误）。
- 打包时把上游标签更新到 v4.2.0，版本名建议 `4.2.0-agent.1`。
