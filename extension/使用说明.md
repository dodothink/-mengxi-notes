# My0511 帖子存档（3.7.0）

> **4.0（Claude 版）更新：存档合并写入**
> 在「设置」里把存档位置选成你的存档文件夹（比如「下载 / My0511存档」）后：同一个帖子永远只有一个 `日期 t帖子号 标题.md` 文件；另一个插件写的同帖文件会被合并进来；楼层只增不减，被删的楼层保留原文并标注「已不可见」；改过的楼层保留全部旧版本；被合并掉的文件移到 `_重复备份/`，不删除。后台采完会自动写文件。
> 图标上出现「授」字，表示浏览器收回了文件夹权限：点开面板，点「存档位置」重新授权，没写成的帖子会自动补写。没选文件夹时和旧版一样写到「下载」，不做合并。


一个 Chrome 扩展，给梦溪论坛（bbs.my0511.com）用。两大功能：

- **存档**：把帖子按楼层存成 Markdown 纯文本，方便离线阅读、检索和长期留存。
- **定时发帖**：提前写好新帖或回复，排进队列，到时间自动发出。

存档只存文字。楼号、作者、发帖时间、IP 属地、发帖设备、引用关系都保留，图片不下载，只在原位留一个 `[图]` 标记。一个几千楼的长帖通常也就几百 KB。

## 安装

扩展没有上架商店，需要手动加载。Windows、macOS、Linux 步骤完全一样。

1. 下载 zip 并解压。**把解压出来的文件夹放在一个固定位置**（比如「文档」里），不要留在下载文件夹。Chrome 每次启动都要从这个路径读取，文件夹被移动或删除，扩展就失效了。
2. 在 Chrome 地址栏输入 `chrome://extensions` 回车。
3. 打开右上角的「开发者模式」开关。
4. 点左上角出现的「加载已解压的扩展程序」，选中刚才那个文件夹（里面应该能看到 `manifest.json`）。
5. 点地址栏右侧的拼图图标，把「My0511 帖子存档」固定到工具栏。

用之前先在浏览器里登录论坛。扩展借用你已登录的身份读取和发帖，不接触你的账号密码。

Windows 上解压时文件夹名可能变成乱码，不影响使用，可以重命名成英文。

### 从旧版本更新

用新文件替换原来那个文件夹里的全部内容（位置不变），然后到 `chrome://extensions`，在「My0511 帖子存档」上点刷新图标。已存的帖子、设置都不会丢。

## 一、存档

点工具栏上的扩展图标，面板顶部有「采集」和「定时发帖」两个标签，存档功能都在「采集」里。

### 存一个帖子

在论坛里打开帖子，点扩展图标：

- **采集整帖**：从第一页读到最后一页。
- **只取新增楼层**：从上次存到的地方接着读，用来跟进还在更新的帖子。
- **导出 Markdown**：把已存的楼层写成文件。

采集在后台进行，每页之间停几秒。面板可以关掉，也可以切到别的标签页甚至关掉论坛页面，不影响采集。中途断了不会丢，重新点一次会接着上次的位置。论坛偶尔限流时，扩展会自己等一会儿再继续。

### 自动跟进帖子

面板里有「自动跟进这个帖子」。勾上以后，扩展每小时自己去看有没有新楼，有就在后台补齐并重写文件，图标上会显示新增的楼数。

### 板块自动巡查

面板下方的「整个板块自动巡查」：每 15 分钟读一遍「百姓话题」的列表页，新出现的主题整帖采集，有新回复的老帖接着上次的楼层补齐。也可以点「立即巡查」手动跑一次。巡查读几页列表，在「设置」里调。

### 批量采集

在版块列表页点扩展图标，它会列出这一页的所有帖子，勾选后点「采集选中的帖子」，排队一个一个采完并自动存盘。

### 存档位置

默认存到「下载 / My0511存档」，重复导出会覆盖同名文件。想换地方，点面板右下角的「设置」，选一个文件夹。这个授权按浏览器记录，换电脑或换浏览器要各选一次。

同一个文件夹里还会生成一份「My0511存档索引.md」，列出所有存过的帖子、楼数和最后采集时间。

### 存出来的文件长什么样

开头是帖子信息：标题、网址、版块、查看和回复数、时间跨度。接着是参与者表格，列出每个人的地区、注册时间、发言数，以及他所有发言的楼号。楼号可以点，相当于论坛的「只看该作者」。

然后是正文，每楼一段：

```
### 10楼 · 网友甲 · 2026-8-25 08:50 · 江苏省 · iPhone 15
> ↩ 回复 [4楼 @网友乙](#f4)

这里是这一楼的正文……
```

引用不再整段重复原文，而是变成指向被引用楼层的链接。在 Obsidian、Typora、VS Code 这类编辑器里打开，链接可以直接点；用纯文本方式打开也能正常阅读。

## 二、定时发帖

### 打开和开关

点扩展图标，切到「定时发帖」标签：

- **开启定时发帖**：总开关，**默认是关着的**。不开的话，队列里的内容不会自动发。
- 面板上显示下一条几点发、还有几条待发、最近一次的结果。
- 点「打开发帖管理」进入完整的管理页面，所有操作都在那里。

发帖用的是当前浏览器里登录的论坛账号。发帖时浏览器要开着，电脑不能睡眠。扩展会在后台开一个标签页填表、点论坛自己的「发表」按钮，发完自动关掉，不影响你用浏览器。

### 添加一条

在发帖管理页的「添加一条」里：

1. **类型**：发新帖，或者回复帖子。
2. **发新帖**：填版块号（百姓话题是 152，其他版块看网址里 f 后面、b 前面的数字）、分类（可不选）、标题。
3. **回复帖子**：粘贴目标帖子的网址。
4. **正文**：纯文字，换行会保留。
5. **什么时候发**：
   - **自动安排**：按下面的规则随机挑时间。还可以限定「不早于」「不晚于」，过了「不晚于」还没轮到就不发了。
   - **指定时间**：到点就发，不受规则限制。
6. 点「加入队列」。

### 批量添加（一次写很多条）

勾选正文框下面的「按分隔符拆成多条」，正文里用单独一行 `===` 把每条隔开：

```
楼主发的，我来看看
===
可以，非常好
===
第三条，可以写多行
也没问题
```

- **回复**：每段是一条回复，都回复到上面填的那个帖子。
- **发新帖**：每段第一行当标题，其余是正文。
- 勾选后会实时显示「能拆成几条」，加入前可以核对。
- 选**指定时间**时：第一条按指定时间，之后每条间隔 N 分钟，还可以设随机浮动。比如间隔 10 分钟、浮动 30%，实际每条隔 7 到 13 分钟。
- 选**自动安排**时：按队列顺序走规则。注意每天的上限，条数多会拖好几天。
- 内容里本来就有 `===` 的话，可以把分隔符换成别的，比如 `###`。

### 队列

每条都标着状态：【待发】【等待重试】【发送中】【已发出】【失败】【已过期】。可以上移、下移调整顺序，编辑、删除、立即发。失败或过期的可以点「重新排队」。已发出的会有「打开帖子」链接。

自动安排的按队列顺序一条一条发；指定时间的到点就发，不管排在哪。

### 自动安排的规则

| 设置 | 默认 | 说明 |
|---|---|---|
| 活跃时段 | 9:00 – 22:30 | 只在这个时间段里发 |
| 每天最多 | 3 条 | 0 表示不限 |
| 最短间隔 | 40 分钟 | 两条之间至少隔多久 |
| 平均间隔 | 180 分钟 | 实际间隔随机，有时近有时远，平均下来是这个数 |
| 每周安静 | 1 天 | 每周随机挑几天整天不发，0 表示不安排 |
| 同帖每天回复 | 不限 | 同一个帖子一天最多回几次，0 表示不限 |

改完点「保存规则」，下一条的时间会按新规则重新排。顶部的「重新随机下一次时间」可以随时重抽一次。

### 出问题时扩展会怎么做

- **没登录或登录过期、出现验证码**：自动暂停，并弹出系统通知。处理好之后点「恢复运行」。
- **论坛提示发帖太快**：过十几到几十分钟自动重试，最多 3 次。
- **提交后等不到结果**：不会自动重发，标记为失败，请到论坛确认有没有发出去再决定，避免重复。
- **同样的内容已经发过**：自动跳过。
- **电脑睡眠或浏览器关着错过了时间**：重新安排，不会醒来后一口气补发一堆。

所有结果都记在页面底部的「发帖记录」里，失败会写明原因。

### 多个账号

每个账号用一个单独的 Chrome 个人资料（Chrome 右上角头像 → 添加）。每个个人资料里各自登录论坛、各自加载一次这个扩展（可以选同一个文件夹），各自有独立的队列和规则。

在一个个人资料里写好的队列，可以用发帖管理页的「导出队列」存成文件，再到另一个个人资料里「导入文件」。

### 导入文件的格式

自己写 JSON 文件也能批量导入，发帖管理页底部有示例：

```
[
  { kind: thread, fid: 152, typeid: 341, subject: 标题, message: 正文 },
  { kind: reply, target: https://bbs.my0511.com/f152b-t9083846z, message: 回复内容 },
  { kind: thread, fid: 152, subject: 标题, message: 正文, at: 2026-10-01 20:30 }
]
```

（上面为了好读省略了引号，实际文件要按标准 JSON 写，直接照发帖管理页里的示例改最保险。）`kind` 为 thread 是发新帖，reply 是回复；`at` 不填就自动安排。

## 说明

- **数据不外传。** 扩展只访问 bbs.my0511.com，不连任何第三方服务器，存档、队列、记录都在本机。
- **权限范围。** 只在 bbs.my0511.com 上生效，别的网站碰不到。
- **用你自己的账号。** 发帖就是你本人在浏览器里发，论坛规则照常适用，别发得太密。
- **地区是论坛显示的。** 「来自 XX」由论坛按 IP 判定，扩展只是照抄。

## 常见问题

**点了没反应？** 确认当前页面是帖子页或版块列表页，刷新一下再点。

**提示需要登录？** 在同一个 Chrome（同一个个人资料）里登录论坛后重试。定时发帖因为没登录暂停的，登录后点「恢复运行」。

**导出的文件找不到？** 看「下载 / My0511存档」；如果在设置里选过文件夹，就在那个文件夹里。

**扩展突然消失了？** 多半是文件夹被移动或删除了。放回原处，或者重新加载一次。

**定时发帖到点没发？** 依次检查：开关开了没有、是不是暂停了、电脑有没有睡眠、浏览器是否开着、这一条是不是被「每天最多」或「安静日」挡到了后面。面板上会显示下一条的具体时间。

**更新后看不到「定时发帖」？** 去 `chrome://extensions` 点一下刷新，版本号应该是 3.7.0。

## 3.1.1 更新

- 采集时遇到论坛的「安全验证」页，不会再把它当帖子存成乱码文件（「瀹夊叏楠岃瘉.md」）。现在会直接进冷却，过一会儿自动接着采；想马上恢复，就在浏览器里打开论坛，手动做一下验证。
- 页面编码按实际情况识别，不再写死 GBK。
- 定时发帖碰到「安全验证」页会暂停并发通知，和碰到验证码时一样：手动过完验证后，在面板里点「恢复运行」。

## 3.2.0 更新：全部停止

- 面板最上面新增「⏹ 全部停止」按钮。点了之后，采集、自动跟进、板块巡查、定时发帖全部停下，不会再被定时器自动拉起来；浏览器重启后也保持停止状态。
- 停止时工具栏图标上显示「停」，面板显示「已全部停止」。
- 正在采的帖子会记住采到第几页，放回队列最前面；点「▶ 恢复运行」后从那里接着采。
- 正在发送的那一条（如果刚好在发）会先发完；定时发帖停止期间错过的时间不会补发，恢复后重新安排。
- 原来帖子页里的「停止」按钮只停当前这一个任务，巡查一到点又会自动开始，所以看起来「停不下来」。

## 3.3.0 更新：批量删除、一律北京时间

- 定时发帖页的队列上方新增：「全选」「删除选中」「全部删除」。每条前面有勾选框，勾几条就删几条；「全部删除」一次清空队列。正在发送的那一条不能删，会自动跳过。删除前会弹框确认。
- 所有时间一律按北京时间（和论坛一致），去掉了「按北京时间计算」开关。页面顶部显示当前北京时间。
- 选「指定时间」时多了快捷按钮：30 分钟后、1 小时后、3 小时后、今晚 20:00、明早 09:00、明晚 20:00。点一下就填好，也可以点输入框右边的日历图标选。

## 3.4.0 更新：采集、发帖分开停止；采集的自动功能默认关闭

- 原来的「全部停止」拆成两个按钮：「⏹ 停止采集」和「⏹ 停止发帖」，互不影响。停了采集，定时发帖照常按时发；停了发帖，采集照常。
- 板块巡查、自动跟进改为默认关闭（升级后也会自动关掉），面板里各有一个勾选框，需要时再打开。这样采集不会在后台自己跑，减少论坛返回 503 / 安全验证的情况。
- 两个都停时工具栏图标显示「停」；只停一个时，鼠标停在图标上会提示是哪一个停了。

## 3.5.0 更新：保留所有修改版本；定时发帖改为并行

- 同一楼层再次采集时，如果内容变了，旧内容不再被覆盖，连同采集时间一起保留。导出的 Markdown 里，改过的楼层下方会列出「第 1 版、第 2 版……」，每版注明首次采集、最后见到的时间（北京时间），论坛自带的「本帖最后由 xx 于 xx 编辑」时间也一并记下。文件开头会列出「改过的楼层」。
- 只能保留插件采集到的版本：两次采集之间改了好几次，中间的版本采不到。「只取新增楼层」只读最后几页，要检查前面楼层有没有改，用「采集整帖」。
- 给了「不早于／不晚于」范围的条目，以你设的范围为准，在范围内随机挑时间发，不再被活跃时段、安静日、每天上限挡住（以前范围落在北京时间夜里或安静日时，会一直排不上直到过期）。
- 定时发帖不再一条接一条排队：每一条都有自己的计划时间，到点就发，互不等待。同一时刻到点的几条，之间只隔 30~50 秒（论坛有发帖间隔限制，同时提交会被拒）。队列里每条都显示自己的计划时间。

## 3.6.0 更新：相对时间

- 「什么时候发」新增「相对时间」，并设为默认：现在就发（1 分钟内）、N 分钟后、未来 N 小时内随机挑时间。不用再算具体几点。
- 「未来 N 小时内随机」按你给的范围来，不受活跃时段、每天上限、安静日限制。
- 批量添加也能用：选「现在就发」或「N 分钟后」时，第一条按这个时间，后面每条按「批量间隔」依次往后排；选「未来 N 小时内随机」时，每一条在这段时间里各自随机。

## 3.7.0 更新：防连帖

- 自动发「回复」之前，先读一下那个帖子的最后一页：如果最后一楼已经是你自己，说明发完上一条后没人接话，这一条就不发，标成「暂缓」，避免一个人对着空帖子一条接一条地自说自话。
- 「暂缓」的条目不会自动再发。要发，点「立即发」（手动发不再检查）；或点「重新排队」，到点时会再检查一次。
- 靠「我的论坛昵称」认出哪一楼是你：第一次回复发成功后插件会自动记下，也可以在发帖管理页的规则里手动填。昵称为空时不做检查。可以在规则里关掉这个功能。
- 发前读不到帖子（比如论坛限流、要验证）时，不会盲发，过 15～30 分钟再试。
- 每次检查要读 1～2 页帖子，会多一点论坛请求。

## 4.2.1 更新：修复板块巡查不按时运行

- 以前「每 15 分钟自动巡查」「每小时自动跟进」的定时器会被浏览器后台反复重置，实际几乎不运行。现在按上次巡查时间判断，到点就巡查。
- 采集队列很长时，巡查不再一直被跳过：每采完一个帖子检查一次，到点就先巡查，再接着采剩下的。
- 到点了但因为「停止采集」或论坛要求验证而没有巡查时，面板会写明原因和时间。

## 4.2.2 更新：「停止」不再清空队列

- 以前在面板点「停止」，除了停下当前帖子，还会把整个待采集队列清空。现在只停当前帖子并暂停采集，队列全部保留。
- 要继续，点面板顶部的「▶ 恢复采集」，从队列里剩下的帖子接着采。
- 面板在暂停或出错时也会显示「队列里有 N 个帖子待采」，不会再看起来像队列没了。
- 某个帖子连续 3 次打不开（每次间隔 5 分钟），就记下原因跳过，接着采队列后面的帖子，不会再卡死整个队列。
- 论坛对坏帖、已删帖返回「提示信息」页（如「未定义操作，请返回」）时，插件会直接记下原因跳过，不再反复重试。
- 当前帖子出错卡住时，面板会出现「跳过这个帖子，接着采下一个」按钮。

## 4.2.3 更新：导出 / 导入队列和设置

- 设置页新增「备份与恢复」：一键导出待采队列、定时发帖、巡查和提醒设置、自动跟进名单，存成一个小文件。换电脑、换浏览器或清了浏览器数据后，在设置页导入就能接着来。
- 导入时队列自动去重；采集先暂停，点「▶ 恢复采集」才开始；定时发帖一律以「暂缓」导入，确认后再点「重新排队」，不会一导入就发出去。
- 断网、论坛临时出错时只会等一会儿再试，不会把帖子当成坏帖跳过。

## 4.2.4 更新：验证后可以直接恢复

- 论坛弹出算术题或要求登录时，面板顶部会写明原因。
- 在浏览器里把验证做完（或登录）后，直接点「▶ 恢复采集」：插件会先试读一页论坛，确认正常就继续采；还不正常会告诉你差什么。

## 4.2.5 更新：巡查间隔可设置、每次随机

- 设置页「自动巡查板块」里可以填「每隔 X 到 Y 分钟随机巡查一次」，默认 10～20 分钟。每次巡查完在这个范围里随机挑下一次，时间每次都不一样；两个数填一样就是固定间隔。
- 面板巡查栏会显示下次巡查大约几点。
